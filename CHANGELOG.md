# Changelog

Notable changes to this project are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and versions follow
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

No version has been released yet. The first tag will be `v0.1.0`, cut from
the state described under Unreleased.

## [Unreleased]

### Added

- VitePress site with guides in English, Portuguese, Spanish and French, each
  with its own nav and sidebar.
- `ScalarApi` component that embeds the Scalar API reference, maps its CSS
  variables onto the VitePress theme (colors, fonts, dark mode) and loads the
  OpenAPI spec that matches the page language. `spec-url` overrides it.
- Example content for the fictional Shelfline Field API: one spec per locale
  in `docs/public/openapi.<locale>.json`, generated by
  [openapi-fixer](https://github.com/rafactx/openapi-fixer), and guide pages
  for authentication, rate limits, examples, pagination and errors.
- Landing page (`HeroSection`, `SpotlightBackground`) and the `ApiCard`
  component used in the guides.
- Deployment to Cloudflare Workers Static Assets (`wrangler.jsonc`,
  `pnpm run deploy`), live at <https://api-docs-starter.rafactx.workers.dev>.
- `pnpm typecheck` (vue-tsc) and a CI workflow that runs install, typecheck
  and build on every pull request.
- Dependabot, CODEOWNERS, issue forms and a pull request template.

### Changed

- Requires Node.js 20 or later and pnpm 10.
- The build fails on dead links (`ignoreDeadLinks` is no longer set).
- Scalar's loading and error states use render functions, so they display
  with the runtime-only Vue build.

### Removed

- Vercel Analytics and Speed Insights, which did nothing on Cloudflare.
- Unused components (`Layout.vue`, `VercelAnalytics.vue`), dependencies and
  the `lint`, `format` and `clean` scripts, which had no configuration behind
  them.
- The unfilled `FUNDING.yml` and the generic Markdown issue templates.
- CSS rules for classes nothing renders, unused design tokens and the unused
  Zilla Slab font.
