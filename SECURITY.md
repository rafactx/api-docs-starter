# Security policy

## Supported versions

Only the latest commit on `main` is supported. Fixes are not backported.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through GitHub: open the repository's **Security** tab and click **Report a vulnerability**.

Include what is affected, how to reproduce it, and the impact you expect.

This is maintained on a best-effort basis. I aim to reply within a week.
